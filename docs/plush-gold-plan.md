# Plush Gold tier plan

Plush Gold is prepared as an optional future premium tier, but **billing is intentionally disabled** while PlushLife is in preview/testing.

## Current access mode

- `PLUSH_GOLD_ACCESS_MODE = "free_preview"`
- `PLUSH_GOLD_BILLING_ENABLED = false`
- Every registered Gold feature resolves as unlocked for every user.
- No Play Billing product, purchase flow, subscription check, paywall, schema change, or third-party billing data flow is activated by this work.

## Core PlushLife stays free

The following are intentionally outside the Gold registry: basic habits and tasks, task completion, Focus Habit, Today, basic check-ins, basic reminders, accessibility, Baby Mode, Low Screen Time, basic progress, and core support/safety experiences.

## Gold registry

### Available today and prepared for future entitlement checks

- Advanced PlushGrowth insights
- Smarter Next Step ranking
- Adaptive habit coaching/background intelligence
- Advanced reminder intelligence
- Habit experiments
- Recovery and comeback intelligence
- Expanded PlushGrowth history
- Advanced planning
- Enhanced sync/history protection

### Reserved for later product work

- Multiple Focus Habits / focus cycles
- Advanced personalization controls
- Gold reports

Reserved means the entitlement ID exists so later product work can use the same access model; it does **not** claim that the feature is already implemented.

## Future activation rule

When monetization is intentionally activated later, change access through a single entitlement resolver rather than scattering purchase checks throughout the app. Billing activation must be a separate deliberate change with Play Billing review, restore-purchase behavior, offline entitlement handling, testing, and store-policy validation.
